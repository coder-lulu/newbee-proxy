## 版本规范

### 版本号格式
采用语义化版本控制 (Semantic Versioning)：`MAJOR.MINOR.PATCH`

- **MAJOR**: 不兼容的 API 修改
- **MINOR**: 向下兼容的功能性新增
- **PATCH**: 向下兼容的问题修正

### 变更类型标识
- ✅ **新增功能** (Added)
- 🔧 **改进优化** (Changed)
- 🐛 **修复问题** (Fixed)
- ❌ **移除功能** (Removed)
- ⚠️ **已知问题** (Known Issues)
- 📝 **文档更新** (Documentation)
- 🧪 **测试相关** (Testing)
- 🔒 **安全修复** (Security)

### 发布周期
- **主版本**: 根据重大架构变更决定
- **次版本**: 每月发布，包含新功能和改进
- **补丁版本**: 根据紧急修复需要随时发布

### 支持策略
- **当前版本**: 完全支持，持续更新
- **前一版本**: 安全修复和关键问题修复
- **更早版本**: 仅提供安全修复（如有必要）
