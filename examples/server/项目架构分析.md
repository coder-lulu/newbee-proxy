# Mayfly-Go 项目架构分析

## 项目概述

Mayfly-Go 是一个基于 Go 语言开发的 DevOps 平台，主要提供机器管理、数据库管理、Redis管理等功能，支持通过 Web 界面进行远程连接和操作。项目采用现代化的微服务架构设计，具有高可用性和扩展性。

## 技术栈

### 后端技术栈
- **语言**: Go 1.24
- **Web框架**: Gin (v1.10.1)
- **ORM**: GORM (v1.30.0)
- **数据库**: 支持 MySQL、SQLite、PostgreSQL、SQL Server、Oracle、DM等
- **缓存**: Redis (v9.8.0)
- **WebSocket**: Gorilla WebSocket (v1.5.3)
- **认证**: JWT (v5.2.2)
- **加密**: AES 加密
- **SSH**: golang.org/x/crypto/ssh
- **日志**: 自定义日志系统 + Lumberjack 日志轮转
- **任务调度**: Cron (v3.0.1)
- **验证码**: base64Captcha
- **LDAP**: go-ldap (v3.4.8)

### 前端技术栈
- **框架**: 基于静态资源打包
- **协议**: WebSocket 实时通信
- **界面**: 响应式 Web 界面

### 2. 核心模块设计

#### 2.1 启动流程 (starter)

**主要文件**: `internal/pkg/starter/`

**启动流程**:
1. `main.go` -> `starter.RunWebServer()`
2. 初始化配置文件映射 (`config.Init()`)
3. 初始化数据库连接 (`initDb()`)
4. 初始化缓存系统 (`initCache()`)
5. 执行数据库迁移 (`migration.RunMigrations()`)
6. 初始化验证器和自定义规则
7. 运行其他初始化方法 (`initialize.InitOther()`)
8. 启动 Web 服务器 (`runWebServer()`)

**特点**:
- 采用优雅关闭机制，支持信号处理
- 模块化初始化，各模块独立启动
- 支持 TLS/HTTPS 配置
- 内置静态资源服务

#### 2.2 机器管理模块 (machine)

**核心组件**:

**MCM (Machine Connection Manager)**:
- `machine.go`: 机器信息管理，支持 SSH 隧道
- `client.go`: SSH 客户端封装
- `sshtunnel.go`: SSH 隧道实现
- `terminal.go`: 终端会话管理
- `stats.go`: 连接统计和监控

**Guacamole 协议实现**:
- `guac.go`: Guacamole 核心连接逻辑
- `instruction.go`: Guacamole 指令解析
- `stream.go`: 数据流处理
- `tunnel.go`: 隧道管理
- `server.go`: Guacamole 服务器实现

**特性**:
- 支持多种连接协议 (SSH, RDP, VNC)
- SSH 隧道跳板机功能
- 会话录制和回放
- 实时连接状态监控
- WebSocket 实时通信

### 3. 核心技术实现

#### 3.1 Guacamole 协议集成

**实现特点**:
- 完整的 Guacamole 协议栈
- 支持 RDP、VNC、SSH 等多种协议
- WebSocket 到 Guacd 的双向数据转发
- 指令解析和状态管理
- 会话管理和资源清理

**核心流程**:
```go
// 1. 建立到 guacd 的连接
func DoConnect(query url.Values, parameters map[string]string, username string) (Tunnel, error)

// 2. WebSocket 到 Guacd 的数据转发
func WsToGuacd(ws *websocket.Conn, tunnel Tunnel, guacd io.Writer)

// 3. Guacd 到 WebSocket 的数据转发  
func GuacdToWs(ws *websocket.Conn, tunnel Tunnel, guacd InstructionReader)
```

#### 3.2 SSH 连接管理

**功能特性**:
- 多级 SSH 隧道支持
- 私钥/密码双重认证
- 会话复用和连接池
- 实时终端交互
- 文件传输支持

**连接流程**:
```go
// 1. 机器连接
func (mi *MachineInfo) Conn(ctx context.Context) (*Cli, error)

// 2. SSH 隧道处理
func (mi *MachineInfo) IfUseSshTunnelChangeIpPort(ctx context.Context, out bool) error

// 3. SSH 客户端获取
func GetSshClient(m *MachineInfo, jumpClient *ssh.Client) (*ssh.Client, error)
```

**安全特性**:

## 学习要点

### 1. 架构设计
- **领域驱动设计** (DDD): 清晰的领域模型和分层架构
- **六边形架构**: API、应用、领域、基础设施分层
- **微服务思想**: 模块化设计，职责单一

### 2. 技术实现
- **WebSocket 实时通信**: 高效的双向数据传输
- **Guacamole 协议**: 远程桌面和终端协议的标准实现
- **SSH 隧道技术**: 安全的网络连接代理
- **会话管理**: 连接状态和生命周期管理

### 3. 工程实践
- **配置管理**: 环境分离和动态配置
- **错误处理**: 统一的错误处理和日志记录
- **资源管理**: 连接池和资源清理
- **安全实践**: 加密存储和权限控制

### 4. 性能优化
- **连接复用**: SSH 连接池和会话复用
- **数据压缩**: Guacamole 协议的数据压缩
- **缓存策略**: 多级缓存提升响应速度
- **异步处理**: 非阻塞的数据传输

这个项目为我们提供了一个完整的远程连接管理平台的实现参考，特别是在 Guacamole 协议集成、SSH 隧道管理、WebSocket 实时通信等方面有很好的实践价值。
